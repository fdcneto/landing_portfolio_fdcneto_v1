# Landing Page - Portfólolio (V1)

Versão inicial do portfólio para publicação. Estilo: *azul com toque artístico e suave*.

## Estrutura
- `index.html` — HTML semântico principal
- `css/styles.css` — estilos
- `js/main.js` — carrossel, formulários e scripts
- `assets/` — imagens e thumbs

## Preparar e editar
1. Substitua as imagens em `assets/` (project-1-800.jpg, thumb-1.jpg etc.).
2. Atualize os links do GitHub e demos no `index.html`.
3. Troque `https://formspree.io/f/SEU_FORM_ID` pelo seu endpoint Formspree (ou outro serviço). Para usar Formspree:
   - Crie conta em https://formspree.io
   - Copie o endpoint do formulário e cole nos atributos `action` dos forms

## Deploy
- Recomendado: Vercel / Netlify / GitHub Pages.
- Deploy rápido: suba o repositório e conecte ao Vercel/Netlify.

## Considerações
- Acessibilidade: elementos com `aria` e teclado suportado no carrossel.
- SEO: preencha `meta` e imagens OpenGraph.
- Performance: gere WebP e otimize imagens.
